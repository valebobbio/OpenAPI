API de Contenido - PPC Crianza (1.0.0)

Download OpenAPI specification:

Contrato del bounded context "Contenido": gestión de Módulos y sus Secciones. Sirve de PLANTILLA de referencia para el resto de los contratos del proyecto (encuestas, usuarios, notificaciones). Convenciones usadas en todo este archivo (repetir en los demás):

  • Rutas en plural, kebab-case si el nombre tiene más de una palabra.
  • IDs siempre como UUID string, nunca int autoincremental expuesto.
  • Campos de dominio en español, camelCase, igual que en el modelo.
  • Todo listado pagina con query params pagina y tamañoPagina, y devuelve el wrapper con contenido + paginacion (ver common.yaml).
  • Todo error usa el schema Error de common.yaml.
  • Los DTOs de entrada (*Input) son distintos de los de salida: nunca se serializa la entidad de dominio directo (regla del modelo: bounded contexts no se exponen crudos hacia afuera).
  • Fechas en formato ISO 8601 (date o date-time según el campo).

Modulos

Gestión de módulos de contenido educativo.

Lista módulos, con filtros opcionales.

Endpoint de uso principalmente del CMS (administradores). La app móvil normalmente solo debería recibir módulos en estado PUBLICADO; eso se resuelve del lado del backend según el rol del token, no con un parámetro que el cliente pueda manipular.

Authorizations:
bearerAuth
query Parameters
estadoPublicacion
string (EstadoPublicacion)
Enum: "BORRADOR" "PUBLICADO" "ARCHIVADO"

Filtra por estado. Si se omite, devuelve todos los que el rol del usuario puede ver.

pagina
integer
Default: 0
tamañoPagina
integer <= 100
Default: 20
